代码与结果文件说明

本压缩包整理了本文建模过程中使用的主要程序与关键结果文件，内容如下：

1. 统计图.py
该文件用于读取原始数据并生成论文中的主要统计图表，包括站点借出量分组图、空间分布图以及代表性站点借出归还对比图，用于展示共享单车站点的基本运行规律。

2. 预测模型.py
该文件用于建立共享单车借还需求预测模型。程序先对历史借还记录进行整理，再构建不同预测方法，并通过误差指标比较模型效果，最终输出后续调度模型所需的工作日预测结果。

3. 最终预测结果_模型2_工作日.csv
该文件为预测模型输出结果，记录了各站点在各小时的预测借出量和预测归还量，是调度优化模型的输入数据。

4. question3.py
该文件用于建立调度优化模型。程序基于预测结果，分别模拟无调度和有调度两种情形，求解最优调度方案，并输出总费用、满桩/空桩发生次数、用户无法借车/还车次数以及用户需求率等结果。

运行顺序建议：
第一步，运行 统计图.py，生成描述性分析图表；
第二步，运行 预测模型.py，生成工作日预测结果；
第三步，运行 question3.py，完成调度优化与结果对比。

运行环境说明：
Python 3.x
主要依赖库包括：
pandas
numpy
matplotlib
pulp
highspy
